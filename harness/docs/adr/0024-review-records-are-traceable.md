# Review Records Are Traceable

Every Cognitive Evaluation Review Record identifies the immutable Bundle, execution
Case, control version, Node Cognitive Control Contract, rubric, and Evaluation Review
Protocol it assessed. It also records evaluator or evaluator-interface identity and
time, the four-state conclusion, supporting evidence, confidence and unknowns, likely
owning layer, first source seam, and proposed follow-up. These links make a result
reviewable rather than detached evaluator prose.
