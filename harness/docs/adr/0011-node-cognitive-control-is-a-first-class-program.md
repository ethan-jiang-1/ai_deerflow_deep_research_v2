# Node Cognitive Control Is A First-Class Program

Every LLM-bearing node is designed, reviewed, tested, and evaluated as a two-part
program. Its Node Cognitive Control Program consists of node-local runtime MD/prompt,
bounded model-visible inputs, and structured feedback that guide the model's work. Its
Deterministic Control Boundary exclusively enforces tools, access, budgets, state,
persistence, routes, and candidate admission. Neither layer replaces the other: hard
code controls do not define cognitive quality, and Markdown cannot take execution
authority.
