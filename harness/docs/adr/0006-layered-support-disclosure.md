# Layered Support Disclosure

When research stops unexpectedly, the dedicated TUI presents three progressively
technical layers: a plain-language outcome and next action by default; a safe
explanation of phase, category, and recovery attempts on request; and a copyable
redacted Support Handoff for seeking help. The handoff includes only useful safe
context such as run reference, version, phase, attempted recovery, and diagnostic
facts. It excludes credentials, raw prompts, raw exception stacks, and private paths.
