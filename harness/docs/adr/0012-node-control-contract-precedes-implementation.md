# Node Control Contract Precedes Implementation

An LLM-bearing node begins with one Node Cognitive Control Contract before its prompt,
code, tests, or evaluation are changed. The contract names its user-serving cognitive
responsibility, input trust boundary, bounded method and tools, candidate quality and
uncertainty standard, feedback/repair loop, and deterministic admission boundary.
Runtime MD, implementation, deterministic tests, and behavioral evaluation must all
refine that same contract; it is not a second runtime authority or a prose afterthought.
