This deterministic-only case evaluates the registered Wave1 extraction and repair method
boundary. Each scenario declares trusted assignment/baseline data plus bounded untrusted
retrieval observations or an initial draft. The runtime bridge enforces tool posture;
the parser, validators, artifact writer, submit validator, ledger, critics, controller,
gate, retry, and route remain outside this fixture.

The two capability and worker-schema digests identify the exact method and response
contract under review. A completed execution is deterministic handoff evidence only; it
does not establish source quality, provider behavior, release status, or selected-live
eligibility.
