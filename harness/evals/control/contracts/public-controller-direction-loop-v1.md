# Public Controller Direction Loop Control Contract

This Case evaluates the committed public controller workflow on ordinary natural-language
turns. The caller must construct the real DeerFlow lead-agent composition, including the
committed `SKILL.md`, dedicated Agent `SOUL.md`, configured `file:read` route, and public
`deep_research` schema. The external model is live; the lifecycle tool may be a bounded
recording fake that returns only declared typed results.

The controller may propose one action or one clarification. It cannot choose a Bundle by
guess, mutate a profile note, create a lifecycle fact, bypass the ordinary skill read, or
turn a typed lifecycle result into a different claim. Every recorded tool call and effect is
review evidence only; Bundle lifecycle admission remains production-owned.
