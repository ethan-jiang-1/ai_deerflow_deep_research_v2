# Wave0 Cognitive Program Control Contract

This deterministic-only case evaluates the registered production Wave0 source-intake
method boundary. Each scenario declares trusted assignment data plus bounded untrusted
retrieval observations or an initial candidate. The production bridge enforces tool
posture and the existing parser, artifact writer, submit validator, ledger, controller,
gate, retry, and route owners remain outside this evaluation fixture.

The two capability and worker-schema digests identify the exact method and response
contract under review. A completed execution is deterministic handoff evidence only; it
does not establish live source quality, provider behavior, release status, or selected-
live eligibility.
