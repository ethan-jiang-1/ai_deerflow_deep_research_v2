# Topic Planning Direction Loop Control Contract

This Case evaluates the production `topic_planning` node through its registered `NODE_SPEC`
and existing real factory. The caller constructs its normal selected-Bundle/profile dependency
path and a live zero-tool capability bridge. The invalid-draft repair scenario may seed only
the declared untrusted first draft so that the production node invokes its real repair
capability; it may not replace parser, materializer, route, or State admission.

The planner receives canonical profile fields and a current-round direction as delimited
assignment data. It cannot call tools, mutate the profile, choose a route, create an artifact,
or grant itself authority. Completion records an execution outcome only; a separate review
judges whether the candidate meets the case rubric.
