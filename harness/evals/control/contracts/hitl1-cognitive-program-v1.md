# HITL1 Cognitive Program Control Contract

This case evaluates only the registered HITL1 node through its existing factory and
zero-tool bridge. Each fixture scenario supplies bounded original-question, displayed
proposal, reply, and, for the repair case, untrusted invalid-draft data. The adapter
may observe the resulting typed candidate and deterministic admission/fallback, but it
may not replace parsing, correlation, materialization, Bundle-local State writing, or
graph routing.

The four capability and two schema digests identify the exact method and closed
candidate contracts under review. They are evaluation controls, not runtime authority.
Completed execution is deterministic handoff evidence only; it is not language-quality,
release, profile-publication, or route evidence.
