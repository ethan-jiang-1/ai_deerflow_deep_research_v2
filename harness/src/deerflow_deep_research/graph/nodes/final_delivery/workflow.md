## Node Identity

Final delivery receives a read-only readiness report plan and accepted-evidence
projection. Its composer may return only complete orders of supplied conclusion and
uncertainty IDs. The deterministic renderer copies the admitted text and submission
references verbatim; the model does not write an artifact or terminal fact.

## From Symptoms

Open `composer.py`, `node.py`, and final-delivery contracts for candidate, publication,
or freshness symptoms; use `tests/unit/test_final_delivery_real.py` first. For runtime
policy or injection symptoms, use `tests/unit/test_research_runtime_capabilities.py`.

## Three Cross-Module Facts

1. The admitted readiness plan and a bounded, delimited accepted-evidence projection
   are the only composer inputs.
2. The composer has a forbidden-tool, one-invocation policy and returns only layout IDs.
3. The publisher re-read and fresh final gate, not a model response or stale report ref,
   own publication verification, routes, and terminal completion.

## Route Facts

Typed final views map `WORK_FAILED` to the existing repair edge and
`EVIDENCE_INSUFFICIENT` to the existing readiness edge. A verified fresh pair passes
the final gate; only that gate projection writes completion.

catalog tests. Treat selected credentialed composition evaluation as supplemental to
