# Start With A Local-First TUI

The first production scope for the dedicated Deep Research TUI is a Local-First
Deployment for one local Primary User. This permits the product to establish reliable
retained Run Bundles, recover available Research State, provide support handoff, and
complete the research journey before
claiming multi-user authorization, shared access, cross-device synchronization, or
remote deployment behavior. Run ownership and isolation remain explicit so a later
approved multi-user design has a trustworthy boundary to build on.
