# Model-Led Research Confirmation Uses Deterministic Fact Admission

Deep Research keeps confirmation as a model-led free-text conversation: the model may
propose, explain, and interpret a user's adjustment. It can return only a candidate;
an Accepted Research Fact comes only from the original user request or explicit user
confirmation after deterministic validation. Research Confirmation produces accepted
facts or one outstanding User Decision, while graph routing, persistence of Research
State within the Run Bundle, terminal handling, and model/provider failures remain
owned outside it. This preserves conversational UX without allowing prompts, model
defaults, or inferred preferences to authorize research scope.
