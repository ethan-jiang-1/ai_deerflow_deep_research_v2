# Keep V1 Evaluation Review Simple

V1 does not add an evaluator-specific runtime Python control, graph node, or Python
judgment engine. A Coding Agent or other approved evaluator conducts the multi-turn
review using a concise, versioned Evaluation Review Protocol and produces the validated
review shape. This retains repeatability while the runner/bundle contract proves its
value; specialized evaluator control is deferred until repeated evidence shows a real
need.
