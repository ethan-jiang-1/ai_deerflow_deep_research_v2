# Completed Reports Remain Portable In Local-First

Each completed Run Bundle retains its readable report while that Bundle remains
available for the Primary User to inspect. The user can copy or export that report as
self-contained Markdown. This is the Local-First delivery boundary; the product does
not yet promise PDF export, online sharing, collaboration, or multi-user publication.
