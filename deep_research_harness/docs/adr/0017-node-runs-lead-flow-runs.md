# Node Runs Lead Flow Runs

The Cognitive Evaluation Runner supports Node Evaluation Runs and Flow Evaluation Runs
under one bundle and execution-status protocol. Node runs are the required primary lane:
each LLM-bearing node has a bounded smoke scenario that invokes its declared production
branch and isolates its cognitive control program. Flow runs remain necessary to observe
node composition and Research Outcomes, but are a separate, lower-frequency integration
lane built from a small curated corpus after node baselines are dependable. Neither lane
substitutes for the other.
