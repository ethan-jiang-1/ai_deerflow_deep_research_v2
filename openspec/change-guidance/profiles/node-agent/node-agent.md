# Node-Agent Profile

> authority: guidance only; owning specifications and executable contracts define behavior
> trigger: changing an LLM-bearing role, capability, tool posture, candidate admission, repair, or model/non-model classification

Enable for an LLM-bearing role, capability, tool posture, candidate admission, repair,
or model/non-model classification. This is the complete cognition-versus-code
contract formerly carried by `node-edit-map.md`; the filename is not the authority.

## Ordered Authoring Route

Read before implementation navigation. Never infer the seam from the first file found
or from presence or absence of a model call.

1. **Classify the surface** as `cognitive-program`, `deterministic-guardrail`,
   `human-decision`, or `wiring`. Model-bearing symptoms reach cognition first unless
   rejected with a causal rationale; non-model work fabricates no prompt.
2. **Node Cognitive Control Contract and local capability**: state bounded responsibility, useful
   candidate, uncertainty/degradation posture, and what the model cannot decide.
3. **Prompt builder and model-visible context**: distinguish trusted assignment/output-contract
   inputs from delimited untrusted content; name requested method/tool posture and its
   runtime enforcer. Guidance and prompts cannot grant tools, permissions, writes,
   routes, retries, or result acceptance.
4. **Structured output, feedback, and repair**: trace candidate shape, feedback
   source and recipient, repair bound, and stop condition. Feedback is data, not
   authority to widen a task, select a route, or admit an effect.
5. **Focused proof and applicable cognitive evaluation**: use the lowest composition/admission
   proof, then state applicable cognitive evaluation and its limitation.
6. **Deterministic handoff owners**: only then inspect parser, evaluator/materializer, ledger,
   gate, graph, and effect owners that admit a legal candidate and choose observable behavior.

## Non-Model Work

For deterministic-guardrail, human-decision, or wiring work without a causal
model-bearing symptom, begin at the typed/domain/control/graph/adapter owner and record
why cognition is not causal. Do not invent a capability, prompt, or repair loop.

The adopting application keeps its exact local source map. That map is a reader
projection, never runtime configuration or a second behavior specification.

## Workflow Integrity

A node agent answers one bounded cognitive question and returns a candidate. Graph or
handler owns placement/state/routes; runtime owns actual tools/sandbox/budgets;
parser/evaluator/materializer owns deterministic admission. Record classification,
input authority, tool enforcer, candidate/admission owner, failure bound, and proof.
