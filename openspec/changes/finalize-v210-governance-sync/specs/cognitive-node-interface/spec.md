# Spec Delta

## MODIFIED Requirements

### Requirement: Product-responsibility-first reader projections

Every current logical node SHALL colocate one non-runtime `workflow.md` projection.
It SHALL title itself with the node's name followed by a one-line
product-responsibility statement in the form `# <node> — <responsibility>`, carrying
the product-responsibility-first intent of this requirement in that title line. It
SHALL then state Participation mode, Commitment state, source-audited Current
operating mechanism, Primary cognitive/control program surface, Deterministic
authority boundary, and audit-only Current model-branch evidence in that order. It
SHALL use Node Identity, From Symptoms, Three Cross-Module Facts, Route Facts, and
Evaluation and Verification Order in that order. It SHALL not create runtime prompts,
model/tool branches, interactions, or graph behavior.

#### Scenario: Active and non-active current mechanisms are readable
- **WHEN** a maintainer opens any logical node projection
- **THEN** it distinguishes active cognition, controller exclusion, conditional human
  decision, or deferred cognition from the source-audited current mechanism
