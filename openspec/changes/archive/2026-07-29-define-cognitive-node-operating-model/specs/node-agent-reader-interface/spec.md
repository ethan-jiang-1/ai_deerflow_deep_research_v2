# node-agent-reader-interface Delta Specification

## ADDED Requirements

### Requirement: Package-local reader obligations coexist with the cognitive-node interface

The existing node-agent-reader-interface capability SHALL remain the owner of the
six package-local workflow.md projections required by NRI-001 and NRI-002. This
Phase 0 change SHALL NOT assert that those six documents already implement the
future all-node fixed shape, create a missing document, or activate a model branch.

cognitive-node-interface SHALL define the product-responsibility-first contract that
a separately admitted all-node reader rollout must apply when it revises the six
existing projections and creates the five additional projections. That rollout SHALL
lead each card with Product responsibility, then separately record Participation
mode, Commitment state, source-audited Current operating mechanism, Primary
cognitive/control program surface, Deterministic authority boundary, and audit-only
Current model-branch evidence. It SHALL name its exact eleven-document and
verification scope.

Neither reader capability is runtime configuration or a source of execution
authority. The current direct model-branch audit cannot be used to reduce the
all-node product inventory to the six existing package-local documents, and a
deferred/conditional product responsibility cannot be used to claim an active model
loop.

#### Scenario: Cross-node inventory includes non-active current mechanisms
- **WHEN** a reader encounters bootstrap, rerun, HITL2, readiness, or final delivery
  in the cognitive-node inventory
- **THEN** the reader can distinguish intentional controller exclusion, conditional
  human-decision opportunity, or accepted deferred cognitive responsibility from the
  current mechanism without inferring an LLM-bearing workflow.md, active tool policy,
  model invocation, or user interaction

#### Scenario: Later all-node reader rollout begins
- **WHEN** a separately admitted change creates or revises the eleven node-local
  reader projections
- **THEN** that change applies the cognitive-node fixed field order and structural
  headings, proves one individual card per logical node, and names its own
  document/checker evidence without retroactively treating this coexistence
  requirement as implementation of any projection

#### Scenario: Existing six reader obligations remain useful
- **WHEN** a maintainer investigates an active HITL1, topic-planning, Wave0, Wave1,
  Wave2, or targeted-evidence symptom before the all-node rollout
- **THEN** NRI-001 and NRI-002 continue to route the maintainer to current owning
  sources and deterministic seams, while cognitive-node-interface does not replace
  those sources with an audit record or generic classification
