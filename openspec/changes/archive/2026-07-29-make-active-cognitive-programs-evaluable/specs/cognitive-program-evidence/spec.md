> req: CPE-001, CPE-002

## Purpose

Make every current direct Deep Research model branch reviewable as one bounded
cognitive program without granting it deterministic workflow authority.

## ADDED Requirements

### Requirement: Every active direct branch has an individual evidence ledger row

The six active logical nodes SHALL maintain one test-owned cognitive-program evidence
row for each current direct model branch. The row IDs SHALL equal both the canonical
prompt-catalog case IDs and `COHORT_EVIDENCE` case IDs exactly. Each row SHALL record
product responsibility, bounded question, trusted/untrusted input boundary, capability
binding, catalog and final-render seam, requested tool window, bridge-enforcement
seam, feedback disposition and recipient when one exists, candidate/admission owner,
guardrail evidence, classified evidence links, and evaluation disposition. A node
aggregate, grouped row, or catalog count SHALL not close a missing branch row; the
ledger SHALL remain a review projection and SHALL not select a prompt, tool, route,
model, candidate, or lifecycle result.

#### Scenario: Branch inventory is reviewed
- **WHEN** maintainers review active cognitive evidence
- **THEN** they can establish exact sixteen-branch coverage and identify the
  composition, feedback, guardrail, and evaluation-disposition proof for each branch

### Requirement: Evidence classes do not overclaim model judgment

Composition, requested-versus-enforced tool posture, feedback delivery or absence,
parsing, and admission SHALL use the lowest deterministic seam. A feedback recipient
SHALL be named only when a bounded datum reaches a later production model request;
trigger-only or partial delivery SHALL record the source seam and omitted datum. A
judgment claim SHALL add an explicit scenario/live rubric and nondeterministic
boundary; otherwise its row SHALL state that deterministic evidence is sufficient
because no judgment claim is asserted. A mocked parser or aggregate count SHALL not
substitute for production branch-transition evidence.

#### Scenario: Judgment proof is required
- **WHEN** a branch claim depends on model judgment rather than deterministic composition
- **THEN** its ledger row identifies a bounded rubric, nondeterministic boundary, and
  required evidence class
