# C-010.a - Final Report Artifact Versus Export

> Stage: 2 - `retire-stale-context-concepts`
> 类型: status split
> 状态: **REVIEW REQUIRED**

## 调整内容到底是什么

保留 Bundle 中 current `report.md` artifact；把 Primary User reopen/copy/export surface
单独定义为 `planned`，不再由文件存在推导用户能力。

## 主要风险

状态拆分可能误删真实 report artifact，或反过来继续把 artifact 路径当 public export
contract。

## 可能副作用

词典多出两个相近术语，读者需要理解 artifact 与 capability 的区别；planned export 可能
长期没有 public owner。

## 控制与停止条件

- current artifact 链接 final-delivery owner。
- planned export 明确无 current entry。
- 不修改 publisher、Bundle 或 public lifecycle API。
